# CATEGORY RULES: BATHROOM EXTRACTION (authoritative — user-supplied, transcribed faithfully, 2026-09-05)

## 2. MOST IMPORTANT CLASSIFICATION RULE
Do NOT classify on the word "Bathroom" alone. Priority:
PRIMARY PRODUCT TYPE > PRIMARY PRODUCT FUNCTION > WEBSITE CATEGORY HIERARCHY > ROOM/LOCATION

## 3. WHAT COUNTS AS BATHROOM
Bathroom Furniture, Fixtures, Accessories, Storage, Ceramics, Sanitaryware, Basins,
Sinks, Toilets, Bidets, Baths, Bathtubs, Showers, Shower Accessories, Bathroom Taps,
Faucets, Hardware, Shelving, Cabinets, Vanity Units, Organizers, Mirrors, Toilet
Accessories, Cleaning Accessories, Soap Accessories, Towel Accessories.

## 4. FIXTURES — include
Toilets, WC, Close-Coupled / Wall-Hung / Back-to-Wall / Rimless Toilets, Bidets,
Bidet Toilets, Urinals, Basins, Sinks, Countertop / Vessel / Wall-Mounted / Pedestal /
Semi-Recessed / Undermount / Cloakroom / Corner / Double Basins, Wash Basins.

## 5. BATHS — include
Bathtubs, Baths, Freestanding, Back-to-Wall, Corner, Straight, Double/Single-Ended,
Roll-Top, Slipper, Whirlpool, Spa, Shower Baths.

## 6. SHOWERS — include
Showers, Shower Systems/Sets/Heads, Hand/Fixed/Rain/Thermostatic/Electric/Mixer
Showers, Shower Columns, Rails, Kits, Panels. Shower-specific accessories when
explicitly in the Bathroom/Shower hierarchy.

## 7. ENCLOSURES & SCREENS — include
Shower Enclosures, Screens, Doors, Cubicles, Panels, Walk-In Showers/Screens,
Quadrant/Offset Quadrant, Sliding/Hinged/Bi-Fold Doors, Bath Screens.

## 8. TAPS & FAUCETS — include
Bathroom Taps/Faucets, Basin Taps/Faucets/Mixers, Bath Taps/Faucets/Mixers,
Thermostatic Mixers, Wall-Mounted Taps, Freestanding Bath Taps.
Metallic products are NOT excluded here. Steel, Stainless, Iron, Aluminium, Brass,
Chrome, Nickel, Copper all allowed.

## 9. BATHROOM FURNITURE — include when the site presents it as Bathroom
Vanity Units, Vanity Cabinets, Bathroom Cabinets, Under-Sink Cabinets, Bathroom
Storage Cabinets, Furniture Sets, Console Units, Tall Units, Floor/Wall Cabinets.
Website hierarchy is the deciding evidence. No duplicates.

## 10. BATHROOM MIRRORS — DO NOT SKIP
All bathroom mirror types: Bathroom, Vanity, Wall-Mounted, Recessed, Round,
Rectangular, Oval, Square, Arched, LED, Illuminated, Backlit, Demister, Anti-Fog,
Heated, Cabinet Mirrors, Mirrored Cabinets, Shaving, Magnifying, Extendable, Tilt,
Sensor, Smart. The words "Bathroom"/"Vanity" must NEVER cause exclusion.

## 11. MIRROR VS LIGHTING (critical)
Primary type = mirror -> BATHROOM (incl. LED/illuminated/integrated-LED mirrors).
Primary type = lighting -> LIGHTING (Mirror Light, Vanity Light, Bathroom Wall Light).

## 12. BATHROOM STORAGE — include when site presents it under Bathroom
Bathroom Storage/Units, Cabinets, Organizers, Baskets, Shelves, Wall Cabinets,
Under-Sink Storage, Tall Units, Toilet Storage, Storage Towers.
Clearly-Storage-owned products belong to Storage.xlsx. Hierarchy decides. No dupes.

## 13. ACCESSORIES — include
Soap Dispensers/Dishes/Holders, Toothbrush Holders, Tumbler Holders, Tumblers,
Toilet Roll/Paper Holders, Toilet Brush Holders, Toilet Brushes, Towel Rails/Rings/
Bars/Hooks, Robe Hooks, Bathroom Hooks/Trays/Caddies, Shower/Bath Caddies, Bathroom
Baskets/Containers/Canisters, Accessory Sets. Bathroom-intended only.

## 14. TOILET ACCESSORIES — include
Toilet Roll/Paper Holders, Brushes, Brush Holders, Caddies, Toilet Storage, Roll
Storage, Toilet Seats, Soft-Close Seats, Bidet Accessories. Preserve site hierarchy;
don't fold the toilet itself into an accessories node when a separate one exists.

## 15. TOWELS — cross-category split
Textile (Bath/Hand/Face Towels, Bath Sheets, textile Bath Mats, Washcloths) -> TEXTILE.
Hardware (Towel Rail/Bar/Ring/Hook) -> BATHROOM.

## 16. BATHROOM MATS
Textile bath mat -> Textile. Rubber / anti-slip mat explicitly sold as a bathroom
accessory -> Bathroom. Website hierarchy decides when ambiguous.

## 17. HARDWARE — include, metal is fine
Towel Rails/Bars, Toilet Roll Holders, Robe/Bathroom Hooks, Shower Rails/Brackets,
Bathroom Shelves, Accessory Sets, Mounting Accessories.

## 18. CERAMICS — include when genuinely bathroom
Ceramic Basins/Sinks/Toilets/Bidets/Accessories/Soap Dishes/Toothbrush Holders.
A decorative ceramic vase used in a bathroom is NOT Bathroom.

## 19. BATHROOM LIGHTING
Must not be skipped during inspection, but classification follows primary type.
Bathroom Ceiling/Wall Light, Vanity Light, Bathroom Pendant/Spotlights -> LIGHTING.
Do NOT duplicate a Lighting record into Bathroom.

## 20. BATHROOM TEXTILES
Bath Towels, Hand Towels, Bathrobes, Shower Curtains, Bathroom Curtains -> TEXTILE.
Bathroom-specific accessories and hardware -> BATHROOM.

## 21. BATHROOM DECOR
Bathroom Vase/Sculpture/Candle -> Decorative Home Accessories. Bathroom Wall Art ->
Wall Decor. Bathroom Mirror -> Bathroom. Bathroom Soap Dispenser -> Bathroom.

## 22. MATERIAL RULE
NO material restriction. Ceramic, Porcelain, Glass, Brass, Chrome, Stainless, Steel,
Iron, Aluminium, Copper, Stone, Marble, Resin, Acrylic, Plastic, Wood, Composite.
Material alone must never exclude.

## 23. NAVBAR EXTRACTION
Start from the site's real navigation: Bathroom, Bathrooms, Bath, Bathroom & Plumbing,
Bathroom Furniture, Sanitaryware, Bathroom Accessories, Showers, Baths, Basins, Taps,
Toilets, Bathroom Storage, Bathroom Mirrors. Then follow the hierarchy and preserve it.

## 24. PARENT CATEGORY URL RULE
Never record the parent URL when valid subcategories exist. Record the deepest valid
listing URLs. A category with no subcategories may use its own URL.

## 25. VIEW ALL / COLLECTIONS — never record
View All, Shop All, All Products, Collections, Gift/Seasonal Collections,
promotional pages, search-result pages.

## 26. QUANTITY
Exact figure shown on the listing page. "142 Products" -> 142.
"Showing 1-24 of 142" -> 142. If no total: paginate and count unique product cards.
NEVER estimate. NEVER infer from pagination without verification. NEVER combine
unrelated category quantities.

## 27. URL RULE
Verified category/subcategory listing URL only. Never product-detail, homepage,
search, View All, collection or promotional URLs. NEVER invent a URL.

## 28. DUPLICATE RULE
Key = Company + Category + Sub-Category + URL. Same URL via multiple nav paths ->
one record. Genuinely different URLs -> separate records.

## 29. AMBIGUITY RULE
Inspect parent category, subcategory, product title, description, purpose, site
terminology, nav context. Never one keyword. "Vanity"/"Cabinet"/"Mirror" must be
disambiguated. If ambiguity remains: confidence = LOW, send to review, do not guess.

## 30-33. NO CROSSOVER RE-EXTRACTION
Do not re-extract general Furniture (tables, sofas, beds, chairs, wardrobes, desks),
general Storage (boxes, bins, baskets, organizers), or general Textile (towels,
curtains, robes, cushions, bedding) merely because the site sells them.
Storage > Storage Baskets = Storage. Bathroom > Bathroom Baskets = Bathroom.

## 34. COMPANY PROCESSING
Check every company independently. Absence from a previous category file is NOT
evidence of no Bathroom. Never re-browse when a validated cached result exists.

## 35. BLOCKED
Never fabricate. Record Company/Country/Website/Status=BLOCKED-FAILED/Reason, move on.

## 36. NO BATHROOM FOUND
Confirmed absence -> Status = NO_CATEGORY. No fake rows.

## 38. GROUPING ROWS
Grouping rows carry blank qty and blank URL. Leaves carry both.

## FINAL PRINCIPLE
Classify on PRIMARY PRODUCT TYPE + FUNCTION + WEBSITE HIERARCHY + PURPOSE.
Not keyword, not room name, not material.
Never skip a valid Bathroom category because its name contains Bedroom, Kitchen,
Vanity, Outdoor, Luxury, Designer, Metal, Glass, Furniture or Storage.
QUALITY > SPEED. NO FABRICATION. NO DUPLICATES. NO QUANTITY AGGREGATION.
NO URL INVENTION. NO SILENTLY SKIPPED BATHROOM SUBCATEGORIES.

## CROSS-CATEGORY DEDUP — mandatory, run at merge time (added 2026-09-05)

Rules 9/12 above ("Clearly-Storage-owned products belong to Storage.xlsx",
Furniture-hierarchy vanities) are OPTION-1 dedup rules: if a candidate leaf's
URL is **already recorded as a leaf** in `Furniture.xlsx`, `Storage.xlsx`,
`Wall_Decor.xlsx` or `Textile.xlsx`, it goes to `review[]` as
`ALREADY EXTRACTED IN <file>`, never to `rows[]` — regardless of which of
those four files' own rules would have "wanted" it. `Seasonal.xlsx` is the
one exception (that category deliberately overlaps every other on purpose)
and must never suppress a genuine Bathroom leaf.

`pipeline/bathroom_json_archive/merge_bathroom.py` enforces this
automatically via `cross_category_url_index.json` — workers do not need to
build this index by hand, but SHOULD still sanity-check an obvious repeat
candidate (a mirror or storage-basket node that clearly duplicates another
category's own listing) before recording it, the same judgement call rule 29
already asks for.
