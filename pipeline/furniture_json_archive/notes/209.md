Note the generic /frontastic/action/product/query catalogue-wide endpoint reports total=8005 but is NOT usable for counts (unstable relevance ordering returns duplicates across offsets: 8100 fetched rows yielded only 6563 distinct products) - the per-category productSearch totals used here are a different, stable code path and were each proven by exhaustion.
