ACCESS/METHOD NOTES: spin.co.in itself returns HTTP 403/410 on direct fetch (domain retired/blocked) - it never loaded. The live operating storefront for the 'SPIN' brand is https://www.madewithspin.com/, a Shopify store; identity confirmed via its own /pages/about-us copy: 'We are an edgy furniture and home-accessories label' (matches brief: Indian decor/lifestyle DTC brand). No separate/other SPIN entry encountered in this session to cross-check against, so this is treated as the single canonical SPIN listing (domain migration spin.co.in -> madewithspin.com, not a distinct duplicate company). Access route: direct Shopify Storefront JSON API (curl_cffi via probe.py), /collections/<handle>/products.json?limit=250, paginated, deduped by numeric product ID - no WAF issues encountered, robots.txt has no Claude-specific disallow. Count verification: Rule 1 applied hard - collection object 'count'/products_count metadata was inflated on several handles (e.g. 'mirror' listed 10 vs 8 true ids after removing a non-mirror shelf SKU; 'lighting'/'candle-candle-holder' listed 8 vs 3 true ids; 'vases' listed 28 vs 18 in-scope ids; 'planter' listed 38 vs 23 valid unique ids; 'candle-holder' listed 62 vs 33 in-scope ids after removing scented candles) - every qty below is a live product-ID enumeration count, not the site's reported count. SPIN is furniture-dominant (sofas, beds, tables, storage - all out of scope and excluded); only decor-accessory, mirror, lamp and kitchen/dining-tableware slices were extracted. Exclusions applied: all furniture/storage/organisers/hooks/hangers/shoe racks (bathroom-accessories and entryway collections dropped almost entirely - only their mirror SKUs were kept, already captured under Mirrors), cutlery/flatware (Hanoi/Oran spoon-fork-knife sets, Aurum Cake Server Set), cookware (Fujihoro Cook & Serve line), textiles (cushion covers, throws, table linen/runners/napkins/covers), placemats and trivets (functional dining accessories, not decor), scented candles confirmed via product copy ('mild natural scent', fragrance notes like cinnamon/cedarwood/musk) - Forest Trail, Noir Notes, Cinnamon Spark, Ridge Pillar Candles, Neon Taper Candles, Ava Tapered Candle - kept only candle HOLDERS/diyas/incense-holders/candle-care tool, jewellery box/stand and desktop/office organisers (pen holders, paper trays, monitor stands, bookmarks). Dried/preserved-flower-only SKUs (Eterna Preserved Flowers, Gypsy Dried Pampas Grass, Serene Dry-Flowers Bunch, Nygel Dried Flowers) excluded as out-of-scope plant/floral matter; the vase-shaped stands that merely display dried flowers were kept as vases. Mixed roll-up collections (e.g. 'kitchen', 'desktop-organiser', 'all-accessories') were title-inspected per item rather than counted wholesale, per the drop-don't-pad rule. Rule 0 gains: none needed - no borderline room-named items were wrongly excluded; the only room-adjacent exclusions (bathroom hooks/hangers, entryway coat racks) were excluded on product-type grounds (storage/hardware), not room name.
