SITE ARCHITECTURE: Muuto is furniture-first (Seating/Sofas/Tables/Storage all excluded per brief). Category pages are server-rendered Vue with a client PLP component (tile-filter) backed by a same-origin JSON endpoint /api/products?pageId=<id>; used this for exact, exhaustion-checked leaf counts (results array length = 'hits' = number of distinct master products/tiles, cross-verified against raw SSR <product-tile master-id=...> tag counts on 3 categories -- vases, mirrors, kitchen -- which matched exactly). QTY VERIFICATION (Rule 1): the API also returns a 'totalHits' field which is consistently HIGHER than 'hits' on several categories (e.g. Wall Lamps hits=9/totalHits=17, Table Lamps hits=14/totalHits=18, Floor Lamps hits=7/totalHits=11, Candleholders hits=2/totalHits=4) -- this totalHits figure counts underlying finished-good/SKU variants (colors/sizes), not distinct products, and is the same kind of inflated aggregate this project has repeatedly found in Shopify/Magento/Searchspring counts, so it was NOT used. Used 'hits' (= enumerated distinct master product count, matching the actual rendered tile grid) as qty throughout. Special case: Candleholders -- SSR grid + API both show only 2 live master products (Pair Candleholder, Float Candlestick) though the page's own UI badge text '${availableTotalResults} items' is bound to the inflated totalHits=4; a search for the 3rd facet value 'The More The Merrier' (visible only in the Family facet list) returns hits:0/totalHits:1 via the same endpoint, i.e. a retired/unavailable product family still lingering in facet metadata -- treated the empirically enumerable count (2) as authoritative. RULE 0 GAINS: included Hangers (7: Avail/Attach/Coil coat hooks & racks, plus the 'Dots' ceramic/metal/wood wall-hook collection) under Decorative Accessories per Rule-adjacent brief text explicitly listing 'hooks, racks' as in-scope decorative metal items -- this category is easy to misclassify as excluded 'storage' but the product type is decorative wall hooks, not furniture storage. Rugs, Cushions, Throws (Accessories) dropped as textiles (explicit exclusion).
