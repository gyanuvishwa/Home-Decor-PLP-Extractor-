## Prior Home-Decor pass (archive c96) status=ok
ACCESS/METHOD NOTES: Angular-Universal SSR site on a Magento backend (bloomreach token present but categoryList/product pages are Magento-rendered, not Bloomreach-driven). Access route: direct fetch with a desktop Chrome UA worked for essentially every category page (no persistent Cloudflare block encountered); WebFetch was used for 2 pages whose product grid never renders in raw SSR HTML (Wall Art hub, Garden Lighting) to confirm their true state. Qty verification: each leaf category page renders a filters-modal button reading literally 'See all N items' (or 'See N item' when 0/1) - this is the site's own live result count and was used as primary evidence, cross-checked against a manual de-duplicated count of product-detail hrefs in the same SSR HTML, refetched independently twice for every row. Where the two disagreed (Table Lamps 37 facet vs 36 own-page; Lamp Shades 17 vs 16; Tumblers 17 vs 15 tiles; Salt & Pepper Shakers 3 vs 2 tiles; Plant Pots with Stands 2 vs 1 tile; Mix & Match Wall Art 50 vs 64 tiles) the page's own rendered 'See all N items' button was trusted per Rule 1 (default to the rendered N-items header); tile overcounts are consistent with the known recommendation-carousel-inflation failure mode, tile undercounts with the known stock/aggregation-drift failure mode. HIERARCHY: Mirrors, Wall Art, Lighting, Photo Frames, Plant Pots, Glassware and Mugs & Cups all have genuine nested sub-category URLs (breadcrumb confirms true parent/child, e.g. Home | Homeware | Glassware | Wine Glasses) so those parents were emitted as ungounted parent rows and only the nested leaves were counted - this deliberately leaves some of each parent's population uncounted where no separate crawlable URL exists (e.g. Mirrors' 'Wall Mirrors'/'Wall Hangings' facet buckets, ~35 items, have no addressable URL - shape/colour facets like mirrors/round, /arch, /gold-mirrors, wall-art/wood|metal|glass|concrete|fabric, vases/glass|ceramic|green|pink|blue, photo-frames/{colour|material}, table-lamps/{colour} all either 301-redirect to their parent or soft-404 when fetched directly, confirming they are client-side facet re-cuts, not real categories, and were excluded). RULE 0 GAIN: found and included 3 room-based Lighting categories not present in the main Lighting quick-links nav at all (Bedroom Lighting=56, Dining Room Lighting=38, Living Room Lighting=59, discovered via a cross-link on the Neon Signs page) plus a 4th, Garden/Outdoor Lighting (by-room/garden/garden-lighting, currently 0 items but a live real page) - a naive worker relying only on the visible Lighting quick-links nav would have missed all 4, worth 153 additional (heavily overlapping-with-Table/Floor/Lamp-Shade-population but genuinely separate URL) product listings; Kitchen Wall Art (76) was also kept in-scope under Rule 0 despite the room word. EXCLUDED as mixed navigational roll-ups whose own quick-link cross-sell blocks show they aggregate furniture/textiles/storage/fragrance alongside decor with no decor-only sub-URL to isolate (Blu Dot/Nordstrom precedent, 'drop, don't pad'): Home Decor (top hub, 97 tiles, superset of Wall Art/Glassware/Lighting/Vases/Plant Pots/Photo Frames/Mirrors + non-decor), Tableware (superset of Plates/Serving Dishes/Jugs/Butter Dishes/Salt&Pepper/Glassware/Mugs/Barware, 'See all 150'), Barware/Home Bar Accessories (mostly bottle openers/cocktail shakers/glass straws/tea towels plus items already counted under Glassware/Wall Art/Wine Racks), Dressing Table Accessories ('See all 118', mixes jewellery boxes + trinket/ring dishes + already-counted mirrors/photo frames/lamps with no decor-only sub-URL), Bedroom Accessories ('See all 402', textile/furniture superset), and all 6 by-room hub landing pages (bathroom/living-room/dining-room/hallway/home-office/garden - each a mixed furniture+textile+storage+decor aggregate; their only unique real decor sub-node, Garden Lighting, is captured separately under Lighting). EXCLUDED per standing category rules: Light Bulbs (bulbs), Diff
