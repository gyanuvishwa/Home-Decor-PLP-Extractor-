ACCESS/METHOD NOTES: Access route: beruru.com sits behind a Cloudflare managed challenge that intermittently blocked the homepage/robots.txt on direct fetch (HTTP 429/JS-challenge) and blocked r.jina.ai; translate.goog (beruru-com.translate.goog) rendered the full site nav (mega menu + mobile slide-nav) cleanly and was used to map the category tree. After that, direct requests.get calls to beruru.com (no proxy) succeeded reliably for all /collections/*/products.json and collection HTML pages used for counting - no persistent WAF block once past the first rate-limited burst. Shopify store (myshopify domain beruru-shop.myshopify.com). Qty method: single-segment collection handles counted by enumerating distinct product IDs via /collections/<handle>/products.json (exact, Rule-1-safe). For collections reached only via nested breadcrumb URLs (e.g. /collections/tableware-serveware/glass, /collections/planters/table-planters, /collections/outdoor-lanterns/floor-lanterns) products.json 404s (not real Shopify handles), so qty was read from the theme's own 'collection-filter__item--count' text on the live filtered page and cross-checked against the actual product-tile titles (a fixed 6-item 'trending' widget - SADGI TABLE/SISNA TABLE/MARINA TABLE/MARINA CHAIR/BUMI LAMP/BUCKINGHAM POT - repeats on every collection page and was excluded from all title counts). For product types with no dedicated URL (Mirrors, Vases, Candle Holder, Pillar Candles) the site exposes them only as product_type filters on the big 'beruru-decor' (nav label DECOR) collection; each filtered URL's own count + title list was fetched and verified directly (not the aggregate sidebar facet count on the unfiltered decor page, which for Pillar Candles read a stale/different number (4) than the actual filtered page (9) - the live filtered-page count was trusted). Clocks has no nav entry at all but on-site search (/search?q=clock&type=product) returns 'Search: 3 results found for clock' (Rhombus Clock, Rustic Rebel Clock, Perching Bird Hanging Clock) - these 3 are tagged product_type=Artefacts on-site and are already inside the Artefacts(53)/qty below, so Clocks is a deliberate cross-listed duplicate count, noted here rather than silently omitted. Figurines (site facet, 3 items) was NOT added as its own row: 2 of the 3 (Turtle Statue, Head Buddha With Holder) are already counted inside standalone Sculptures(97); only 1 (wooden figurine) is unique, not enough to justify a separate line without double-counting - folded into notes only. Excluded as out of scope: all Furniture (seating/tables/cabinetry/doors), Garden Accessories (Tools/Watering Cans/Aprons/Baskets), Faux Plants and Flowers, Rugs, Cushions & Covers, Doormats, Rain Chains (0 live products anyway), Birdbaths (garden water feature - Cast Iron Bird Bath, Saras Bird Bath), Fountains (36 products, all outdoor garden water fountains - ARASH/TALAY/CASSIAN/HENSLY etc. - not in the decorative-accessories/lighting/mirrors/tableware include list, treated as a garden feature akin to garden accessories rather than in-scope decor), Cutlery, Barware, Boards/Utility (cutting/serving boards = kitchen utility), Place Mat (textile), the Drinkware 'Bottle' sub-link (mislinked on-site to the whole tableware-serveware collection, not a real distinct product set), Diwali (Holiday), Stationery, Plant Care. The 'Candles' collection (55 items) is a mixed roll-up of scented jar/tealight candles and unscented decor pillar candles - dropped per mixed-rollup rule; only the clean 'Pillar Candles' sub-view (9, all unscented - tapered/acrylic-body/tea-light/LED) was kept as it is explicitly filed as unscented decorative candles in scope.
