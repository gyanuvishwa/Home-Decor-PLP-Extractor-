ACCESS/METHOD NOTES: RULE 3 / SITE IDENTITY: made.com is LIVE but is no longer the original Made.com business. After the 2022 administration Next plc bought the brand and www.made.com is now a Next-operated storefront running Next's own e-commerce platform. Proof: footer of https://www.made.com/ reads '(c) 2026 Next Retail Ltd trading as Made United Kingdom. All rights reserved.'; response headers carry Next infrastructure markers (x-origin-route, NextDeviceType cookie, CSP frame-ancestors 'iguidewebapp.next-uk.next.loc'); URL scheme is Next's /shop/<dept>/<cat> with /f/<facet> filter paths. The catalogue is a multi-brand assortment (MADE.COM, The Set, next, The Conran Shop, Jasper Conran London, Gallery Home, Karlsson, Eglo, La Redoute Interieurs, OYOY Living, Blomus, East End Prints, Paper Collective) - i.e. Next's homeware range sold under the Made fascia, not the old Made.com own-design range. Whole-store catalogue is 1,758 products.  ACCESS ROUTE: direct curl got the homepage and robots.txt but every /shop/ path returned 403. A curl_cffi profile sweep (chrome110/116/119/120/123/124/131 all 403) succeeded on safari17_0, which was used for everything. No proxy, no translate.goog, no browser automation.  TAXONOMY: https://www.made.com/sitemap-index.xml -> Made-GB-EN-Category.xml.gz gives 12,114 URLs but only 45 are non-facet category paths and the list is incomplete (e.g. /shop/lighting/outdoor-lighting and the whole /shop/tableware branch are missing from it). The authoritative tree is the 'category' filter block embedded in each department page's SSR JSON: every category: facet has a clean sibling URL (/shop/<dept>/<slug>) and the child counts sum exactly to the parent total (Lighting 159+57+49+36+26+13 = 340 = search.totalResults; Home Accessories 95+32+18+9+7+7+5+2+2 = 177 = search.totalResults). /shop (Shop all) exposed the complete 76-node store taxonomy with counts, which is how the un-navigated /shop/tableware department and the orphan 'bowls' node were found.  COUNT METHOD: qty is the page's own search.totalResults, INDEPENDENTLY PROVEN by exhaustion on unique structured product IDs. The SSR payload carries an itemsCache keyed by offset (0,12,...,72) = first 84 itemNumbers; ?p=N shifts the window to offset (N-1)*12, so pages p=1,8,15,... enumerate the whole listing. Unique itemNumber count equalled totalResults on 17 of 17 leaf categories (e.g. wall-art 95 IDs = 95; lighting/f/room-livingroom 229 IDs = 229; tableware 68 IDs = 68). itemNumber is a structured product-ID field, not an href count. No rendered 'N items' header exists on this site (the only count string in the HTML is the i18n template '0 results'), so the JSON total + exhaustion is the only available evidence and it survived the check.  COUNT DRIFT: two categories moved between reads within the session - Ceiling Lights 158/159/158 and Floor Lights 36/37. Both are flagged; the qty recorded is the exhaustion-verified unique-ID count (159 and 36 respectively). Lighting room counts also drifted slightly from the parent-page facet snapshot (bedroom 94->93, dining 91->90, office 20->21); the recorded values are the ones proven by exhaustion on the room page itself.  RULE 0 / ROOM-vs-TYPE: Lighting exposes a Room branch (Living Room, Bedroom, Dining Room, Office, Bathroom) with its own indexed canonical URLs present in the category sitemap. Per Rule 0.1/0.6 all five are included as a second parent group, INCLUDING Bathroom Lighting (19) and Bedroom Lighting (93), which the old room-exclusion rule would have dropped. DOCUMENTED OVERLAP: these 452 room-tagged rows are the same products as the 314 type-tagged rows (Ceiling/Desk-Table/Wall/Floor/Outdoor); a product can carry several room tags, so the room branch double-counts against the type branch and against itself. It is the site's own taxonomy, emitted under its own parent row as Rule 0.6 requires. Made has NO room branch under Home Accessories or Mirrors, so no room rows exist there.
