LOCALE: site renders natively in English; canonical tag on every page resolves to the /en-us/ locale path regardless of entry URL (confirmed: unprefixed https://www.finnishdesignshop.com/lighting/ceiling-lamps 200s and self-canonicalizes to /en-us/lighting/ceiling-lamps) - no translation needed, matching the brief's Nordic-retailer expectation (consistent with S.N. 149 Nordic Nest and S.N. 150 RoyalDesign). QTY METHOD: the storefront is a Vue SPA over a PHP backend; category pages render only a skeleton loader server-side (no SSR count), the real listing is fetched client-side from a first-party JSON API discovered by reverse-engineering the site's own JS bundle (assets/ApiCatalogProducts-*.js): GET /api/v1/catalog/products?qs=<urlencoded JSON {uri, language, region, perPage, page, fields}> returns data.products.pagination.total. IMPORTANT: 'uri' must be the bare category path WITHOUT the /en-us locale prefix (e.g. '/lighting/ceiling-lamps') - passing the locale-prefixed path silently drops the category filter and returns the whole-catalogue total (22519) instead, a trap verified and avoided throughout. The same API also returns the live category tree (additional.categories.path[-1].children) with real category IDs/paths, which was used to enumerate the full type tree (this surfaced several sub-categories absent from the mega-nav, e.g. Candle snuffers, Tealight holders, Scented candles, Fireplace accessories, Holiday decorations).
