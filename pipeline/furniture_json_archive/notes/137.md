IMPORTANT CAVEAT: the raw Algolia index itself (queried directly via its exposed public search key) is INFLATED - it indexes one record per SKU/variant plus a parent 'variable_X' record (e.g. Candles: site SSR total=149 vs raw Algolia nbHits=292 for the same category), so raw Algolia hit counts were used only to sample product names for content verification, never as the qty source; qty always comes from the site's own deduplicated productsContainer.totalProducts (the number that actually drives the site's own pagination/rendering).
