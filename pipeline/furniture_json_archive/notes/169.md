Real robots.txt retrieved via a Wayback Machine snapshot: only 'User-agent: GPTBot / Disallow: /' is a full-site block; 'User-agent: *' is restricted only to internal Magento admin/system paths (app/, bin/, checkout/, customer/, wishlist/, etc.) and index.php-style URLs, not to product/category browsing.
