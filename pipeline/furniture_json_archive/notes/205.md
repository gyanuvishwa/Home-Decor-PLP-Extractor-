SCOPE DECISIONS: site organizes lighting primarily by fixture type (Chandeliers, Track Lighting, Pendants, Flush Mounts, Recessed, Table Lamps, Floor Lamps, Outdoor Lighting, Sconces, Picture Lights, Under Cabinet Lights, Bathroom (vanity) Lighting -- kept in scope per Rule 0 despite the room word, Wall Lamps, Wall Lights, Lamp Shades, Night Lights, Up Lights & Clip Lights, Grow Lights, Party Lights) with style_/location_/usage_/feature_/manufacturer_ URL segments nested under each as pure attribute facets of the SAME product (e.g. chandeliers/style_farmhouse, floor-lamps/type_arc-lamps) -- these were NOT extracted as separate rows since they are subsets already counted in the parent total, consistent with Rule 1's caution on fragmenting a single search index. Mirrors was treated the same way (type_vanity-mirrors / type_wall-mirrors are nested facets of the same '/c/mirrors/' listing) so Mirrors is a single childless leaf.
