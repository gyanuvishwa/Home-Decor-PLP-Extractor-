## Prior Home-Decor pass (archive c47) status=ok
ACCESS/METHOD NOTES: WHAT THIS SITE IS TODAY: bedbathandbeyond.com is NOT the original Bed Bath & Beyond retailer, which was liquidated in 2023. The domain is now operated by Beyond Inc. (formerly Overstock.com), which bought the brand and relaunched it on the Overstock e-commerce platform. Confirmed from the origin HTML itself: the page state carries Overstock platform flags ("isOverstock":false, "isBackyard":false, "isBuyBuyBaby":false), product images are served from the Overstock CDN ak1.ostkcdn.com, product URLs use the Overstock /<Dept>/<slug>/<id>/product.html form, footer social links still carry aria-labels reading 'Overstock on Facebook/Instagram/X/Pinterest/YouTube', and the store card is the 'Overstock Mastercard'. The homepage also shows a cross-brand bar linking to containerstore.com, consistent with the group consolidation seen last batch on Kirkland's. So this is a live, very large marketplace-style catalogue - not a retired one - but it is Beyond Inc.'s catalogue wearing the Bed Bath & Beyond name.

ACCESS ROUTE: the homepage fetched directly (HTTP 200) but every /c/ category listing was Akamai 403 'Access Denied'. A 13-profile curl_cffi sweep failed - only safari18_0_ios got a 200, and that was an Akamai Bot Manager behavioural interstitial, not content. r.jina.ai was also 403. The route that worked was translate.goog (www-bedbathandbeyond-com.translate.goog/<path>?_x_tr_sl=en&_x_tr_tl=es&_x_tr_hl=en), which returns genuine server-rendered origin HTML including the count header. All link values below are the canonical bedbathandbeyond.com origin URLs.

COUNTS AND HOW THEY WERE VERIFIED: every category page server-renders three independent count signals - the visible header ('1 - 60 of N Results'), an embedded "resultCount":N, and a JSON-LD ItemList "numberOfItems":N. All three agreed on every row emitted. Verified empirically by exhaustion on Stained Glass Panels (208): paginating &page=1..4 and collecting unique product IDs out of the JSON-LD product-container gave a union of exactly 208 (60+60+60+28), and &page=5 fell back to page 1. Note each page's JSON-LD carries 81 tiles, not 60 - the extra 21 are a next-page prefetch that overlaps the following page (p1&p2 overlap 21, p1&p3 overlap 0), which is why tile-counting overstates and the reported total is the correct number.

RE-CUTS DROPPED (verified, not assumed): 'Framed Art' (42,542) is a cross-cut, not a branch - 25,730 Framed Canvas + 16,812 Framed Prints = 42,542 exactly, and a page-1 ID sample overlapped Framed Canvas 33/60 and Framed Prints 13/60 with zero overlap against Wrapped Canvas. Dropped. Likewise 'Wall Art Sets' (980) overlapped Framed Canvas Sets 75/135, and the four '...Sets' nodes sit inside their parent types (Canvas Art 62,197 = 36,467 Wrapped + 25,730 Framed exactly; Printed Art 16,948 = 16,812 Framed + 136 Unframed exactly) - all dropped. 'Alarm Clocks' (42) dropped: 861 Wall + 225 Tabletop + 6 Floor = 1,092 = the Clocks parent exactly, and alarm clocks overlapped Tabletop 22/42. 'Kitchen Island Lights' (9,269) dropped as a re-cut of Pendant Lights (25/60 sample overlap). Broad parent roll-ups (Decor, Wall Decor 37,907, Decorative Accessories 21,085, Art 92,906, Ceiling Lights 24,010, Lamps 7,919, Barware and Drinkware 7,995) are emitted as parent grouping rows only, never with a qty. Desk Lamps vs Table Lamps and Mugs vs Drinking Glasses were checked and showed 0% overlap, so both were kept.
