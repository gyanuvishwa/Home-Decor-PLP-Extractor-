## Prior Home-Decor pass (archive c265) status=partial
ACCESS/METHOD NOTES: ACCESS: robots.txt (fetched via r.jina.ai proxy since even robots.txt triggers Flipkart's reCAPTCHA wall on a bare request) carries no Claude-specific disallow -- only generic 'User-agent: *' blocks (search/facet/review/AMP paths) and named allowances for Googlebot/Adsbot/Storebot, so proceeded normally per Rule 2. Direct requests.get and a bare r.jina.ai render both hit Flipkart's reCAPTCHA interstitial / an unhydrated SPA shell with no product data. Working route: curl_cffi Chrome impersonation with a real Session (visit https://www.flipkart.com/ first for cookies, then GET the target listing URL) -- this reliably returns full SSR HTML containing a window.__INITIAL_STATE__ JSON blob with the page's FILTERS widget (facetResponse.count + facets) and product list. SCOPE: enumerated only the /home-decor/ department via the site's own sitemap_s_store-browse.xml.gz (236 URLs), not the whole marketplace, per Amazon/Target precedent. STRUCTURE FINDING: Flipkart runs two parallel, overlapping category trees under /home-decor/ -- one rooted at sid=arb (the primary 'Home Decor' store front, https://www.flipkart.com/home-decor/pr?sid=arb) and one rooted at sid=1m7 (a broader decor/lifestyle vertical that also includes out-of-scope Festive Decor, Religion & Devotion, Hookah, and Garden & Leisure branches, all excluded here). Where both trees exposed a same-named node (mirrors, photo frames, book ends, candles, vases) product-ID and/or count sampling showed heavy-to-total overlap, so only ONE canonical row per real category was kept (documented per-row) to avoid padding the sheet with duplicates; the 1m7 tree was used only for Lighting (absent entirely from the arb tree -- kept per Rule 0's Lighting mandate) and a handful of genuinely unique leaves (candle holders/led candles/tealight holders, decorative platters, barn signs, rainbow makers, pocket watches). QTY RELIABILITY (why status=partial, qty mostly null): repeat fetches of the IDENTICAL listing URL returned materially different facetResponse.count values (Decorative Mirrors: 4753 then 5407; Photo Frames-style variance elsewhere too), and an entire branch of deep 1m7 showpiece/flowers sub-type nodes returned an identical implausible 52298 regardless of which sub-type filter was requested (clearly a broken/fallback facet response, not real per-category counts, confirmed across multiple browser-impersonation profiles). Per Rule 1 this widget cannot be certified exact, and an exhaustive pagination/product-ID-dedupe walk across dozens of multi-thousand-SKU categories was not feasible within scope, so qty is null with a MANUAL REVIEW flag on every leaf row; the last-observed count is still quoted in each row's evidence for reference. EXCLUSIONS applied: Home Fragrance (aroma oils/diffusers/potpourri/incense), artificial/faux flowers & plants, fresh flowers, wallpapers/wall decals/stickers, Festive Decor & Religion/Devotion (Holiday & Gift equivalent), Hookah accessories, Garden & Leisure (swings/hammocks/garden fountains), photo albums, trophies & medals, flags, fridge magnets, coasters, pocket lighters, watch boxes, candle moulds, telephone mouthpieces, religious idols, and the 'home-decor-combo' mixed roll-up bucket (dropped per the mixed-roll-up rule rather than padded).
