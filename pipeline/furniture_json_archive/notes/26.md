HAY's own catalogue site is www.hay.com, whose country selector lists USA and lands on www.hay.com itself (all countries land there; only a Hay.countrySelected cookie is set). Rows therefore come from www.hay.com, HAY's own US-facing English catalogue. Re-fetching three PLPs with Cookie 'Hay.countrySelected=USA' returned identical tile counts (31/29/13), confirming a single global catalogue. www.hay.com is a brand catalogue with no prices or cart, and publishes NO 'N items' header anywhere. Every qty here is therefore an exhaustive enumeration of the server-rendered product tiles: each PLP emits one <div class="hayproduct"> per product with pagingSettings pagingEnabled:false and showCount:0, and its 'show more' button only unhides already-rendered .mix-item nodes -- so the initial HTML contains the complete list (verified: mix-item count = hayproduct count + 1 intro text block on every category, and zero collection-rollup tiles, unlike furniture PLPs such as /seating/chairs which do carry COLLECTION tiles). Cross-check: sitemap-products.xml is a superset (51 table-lamp URLs vs 31 listed) because it retains discontinued products, so the PLP is the live curated listing.
